# 파일 탐색기 (com.offlinefiles.explorer)

오프라인 전용 Android 파일 관리자입니다. Kotlin과 Jetpack Compose로 만들었습니다.
최소 Android 8.0(API 26), 대상 API 36이며 인터넷 권한이 없습니다.

## 기능

- **저장소**: 내장 메모리, SD 카드, USB(OTG)와 각각의 사용량을 보여 줍니다. 연결하거나 분리하면 자동으로 반영합니다.
- **USB 저장소 (OTG)**
  - USB 메모리를 꽂으면 홈 화면의 저장소 목록에 나타나고 ‘연결됨’ 알림이 뜹니다. 보고 있던 USB를 빼면 홈으로 돌아갑니다.
  - 픽셀 등 많은 기기는 USB 저장소를 다른 앱에 경로로 공개하지 않습니다. 이때 카드에 ‘탭해서 접근 허용’이 표시되고, 누르면 안내 후 시스템 파일 선택 화면이 USB 저장소에서 열립니다. ‘이 폴더 사용’ → ‘허용’을 한 번 누르면 같은 USB를 다시 꽂아도 다시 묻지 않습니다.
  - 내장 메모리와 같은 기능: 목록·격자 보기, 정렬, 검색(하위 폴더 포함), 미리보기 이미지, 폴더 항목 수, 사진 뷰어, 다른 앱으로 열기·공유
  - 파일 작업: 새 폴더·새 파일, 이름 변경, 삭제, 속성, 내장 메모리 ↔ USB 복사·이동(이름 충돌 처리 포함). 복사가 끝나면 USB에 기록을 마치므로 바로 뽑아도 됩니다.
  - 압축: USB에 있는 zip·7z 보기·풀기, USB에 압축 만들기. 압축 라이브러리는 실제 파일이 필요해서 앱 캐시에 잠시 복사해 처리한 뒤 지웁니다.
  - Android 8–10에서 쓰기가 막힌 SD 카드·USB는 ‘읽기 전용’으로 표시되고, 접근을 허용하면 파일을 바꿀 수 있습니다.
  - 설정 > 저장소에서 허용한 USB 접근 권한을 해제할 수 있습니다.
  - 제한: 파일 선택 화면으로 연 USB는 수정한 날짜를 바꿀 수 없어서, USB로 복사한 파일은 복사한 시각이 날짜가 됩니다. 이런 USB의 사진은 Android 미디어 목록에 없어서 갤러리에는 나오지 않습니다(파일 목록에서 누르면 뷰어로 열립니다). Android가 마운트하지 못하는 형식(예: 일부 기기의 NTFS)은 열 수 없습니다.
- **탐색**: 목록·격자 보기, 정렬(이름·날짜·크기·종류), 숨김 파일 표시, 경로 표시줄, 빠른 접근 폴더
- **검색**: 현재 폴더 또는 하위 폴더까지
- **파일 작업**
  - 길게 눌러 다중 선택한 뒤 복사·이동(붙여넣기 바), 이름 변경, 삭제, 공유, 속성
  - 새 폴더·새 파일, 다른 앱으로 열기
- **이름 충돌 처리**: 덮어쓰기, 합치기(폴더), 둘 다 유지, 건너뛰기, 남은 항목에 모두 적용
- **압축 (zip·7z)**
  - 압축 파일 내용 보기, 전체 또는 선택 항목 풀기
  - 압축 만들기: 수준 4단계, AES-256 비밀번호
  - 분할 7z(.001, .002…), 한글(CP949) 파일명 zip 지원
  - 압축 파일 안의 위험한 경로(zip slip) 차단
- **갤러리** (1.1.0)
  - 홈 화면의 갤러리 카드에서 사진·동영상 수와 최근 항목을 보고 바로 엽니다.
  - **사진** 탭: 모든 사진·동영상을 날짜별로 묶어 최신순으로 표시합니다. 두 손가락으로 오므리거나 벌리면 격자 크기가 바뀝니다.
  - **앨범** 탭: 폴더별 앨범(카메라가 맨 앞), 모든 동영상을 모은 ‘동영상’ 앨범. SD 카드·USB 앨범은 아이콘으로 구분합니다.
  - **뷰어**: 좌우로 넘기기, 두 손가락 확대, 두 번 탭 확대, 움직이는 GIF·WebP, 상세 정보(해상도·카메라·촬영 정보·GPS)
  - 공유, 삭제, 이름 변경, 복사·이동, 압축, 폴더에서 보기, ‘다음으로 사용’(배경화면 등)
  - 파일 목록에서 사진을 누르면 내장 뷰어로 열고 같은 폴더의 사진을 넘겨 봅니다. 설정에서 끌 수 있습니다.
  - 동영상은 재생 버튼을 누르면 내장 플레이어로 재생합니다.
  - Android의 미디어 목록(MediaStore)을 읽으므로 `.nomedia`가 있는 폴더와 숨김 폴더는 보이지 않습니다. 인터넷 권한은 그대로 없습니다.
- **내장 플레이어** (동영상·음악)
  - 파일 목록이나 갤러리에서 동영상·음악을 누르면 앱 안에서 재생합니다. 같은 폴더의 동영상(음악이면 음악)이 재생 목록이 되고, 끝나면 다음 파일로 넘어갑니다. 압축 파일 안의 동영상·음악도 같은 플레이어로 엽니다.
  - MX Player식 조작: 탭하면 조작부 표시·숨김, 화면 좌우를 두 번 탭하면 10초 이동(계속 탭하면 누적), 가운데를 두 번 탭하면 재생·일시정지, 좌우로 밀어 탐색, 왼쪽을 위아래로 밀어 밝기, 오른쪽은 볼륨, 두 손가락으로 확대, 길게 누르는 동안 2배속
  - 화면 맞춤(화면에 맞춤·잘라서 채우기·늘리기·원본 크기·16:9·4:3), 화면 회전(동영상 방향·가로·세로), 조작 잠금, PIP 모드
  - 재생 속도 0.25~4배, 반복(한 개·전체), 무작위 재생, 구간 반복(A-B), 취침 타이머, 이어서 재생(마지막 위치 기억), 남은 시간 표시
  - 자막: 동영상 옆의 .srt·.smi·.vtt·.ass 파일을 자동으로 켭니다(이름이 같은 파일, 한국어 파일 우선). 여러 언어가 든 .smi는 언어별로 고를 수 있고, CP949(EUC-KR) 자막도 깨지지 않습니다. 크기·싱크(0.1초 단위) 조절, 동영상에 내장된 자막 트랙
  - 오디오 트랙 선택, 음악은 앨범 아트·제목·아티스트 화면과 무작위·반복 버튼
  - 이어폰을 빼면 일시정지, 이어폰·블루투스 버튼으로 재생·일시정지·이전·다음, 전화 등 다른 소리가 나면 일시정지 후 다시 재생
  - Android 기본 디코더(MediaPlayer)를 쓰므로 기기가 지원하는 형식만 재생합니다(MP4·MKV·WebM·3GP·TS, MP3·AAC·FLAC·OGG·WAV 등). AVI·WMV·FLV처럼 지원하지 않는 파일은 ‘다른 앱으로 열기’를 안내합니다.
  - 앱을 나가거나 화면을 끄면 일시정지합니다(백그라운드 재생은 없음). 설계와 VLC 기능 비교는 `docs/player.md`에 있습니다.
- **설정**: 테마(시스템·라이트·다크), Material You 색상, 미리보기 이미지, 폴더 항목 수, 사진을 앱에서 열기, 동영상·음악을 앱에서 재생, 이어서 재생, 오픈소스 라이선스
- **언어**: 한국어, 영어
- `Android/data`, `Android/obb`는 Android 11부터 시스템 정책상 열 수 없어서 안내 화면으로 처리합니다.

## 빌드

1. Android Studio에서 이 폴더를 열고 실행합니다. 명령줄에서는 `./gradlew assembleDebug`를 씁니다.
2. 릴리스 서명을 하려면 키 백업 zip에 든 `upload-keystore.jks`와 `keystore.properties`를 프로젝트 루트(이 README가 있는 곳)에 둡니다.
3. 그다음 아래 명령으로 빌드합니다.
   - Play 업로드용 AAB: `./gradlew bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`
   - 직접 설치용 APK: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
4. 두 키 파일은 `.gitignore`에 들어 있습니다. 공개 저장소에 올리지 마세요.

## Play 스토어 업로드

- `MANAGE_EXTERNAL_STORAGE`(모든 파일 접근)와 `REQUEST_INSTALL_PACKAGES`는 Play 정책상 제한 권한이라 심사 대상입니다.
  Play Console에서 파일 관리자가 핵심 기능이라는 권한 선언을 제출해야 합니다.
- 패키지명 `com.offlinefiles.explorer`는 첫 업로드 후에는 바꿀 수 없습니다. 바꾸려면 `app/build.gradle.kts`의 `applicationId`를 먼저 수정하세요.

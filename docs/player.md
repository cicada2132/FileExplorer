# 내장 플레이어

파일 탐색기 안에서 동영상과 음악을 재생하는 플레이어입니다. 기능은 VLC for Android를 기준으로 고르고,
화면과 조작은 MX Player를 참고했습니다.

## 제약과 선택

- 처음에는 ‘새 라이브러리 금지’ 규칙 때문에 **Android 기본 `MediaPlayer` + `TextureView` + Compose**만으로 만들었습니다.
  규칙이 없어진 뒤 **libVLC**(`org.videolan.android:libvlc-all`, LGPL 2.1+)를 넣었고, 지금은 사용자 결정에 따라
  **VLC가 유일한 엔진**입니다. Android 기본 플레이어는 재생에 쓰지 않고, 설정이나 메뉴로 VLC를 끌 수 없습니다.
  - VLC는 준비 단계가 없어서 음소거로 시작해 첫 프레임에서 멈춘 것을 ‘준비 완료’로 씁니다.
  - 파일 안 자막 트랙은 VLC가 영상 위의 투명한 `TextureView`(자막 전용 surface)에 그립니다.
    옆의 자막 파일은 앱이 직접 그리고, VLC가 같은 파일을 또 읽지 않게 `--no-sub-autodetect-file`을 씁니다.
  - 표면 처리: 자막용 표면은 모든 동영상에 미리 만들어 두어 VLC가 시작할 때 함께 붙이고, 재생 중에는 다시 붙이지 않습니다.
    해제할 때는 `stop()` 다음에 표면을 뗍니다.
  - 크기: 네이티브 코드가 CPU 종류마다 40~60MB라 APK를 CPU별로 나눕니다(arm64 APK 약 +26MB). Play용 AAB는 자동으로 나뉩니다.
  - 동영상·음악은 다른 앱으로 넘기지 않습니다. 설정의 ‘앱에서 재생’ 항목을 없앴고, 오류 화면·메뉴의 ‘다른 앱으로 열기’도
    없앴습니다. 파일 메뉴의 ‘다른 앱으로 열기’는 동영상·음악에는 나오지 않고, `openWith`/`openAs`도 미디어는 앱에서 재생합니다.

## 코덱 설정 (안정성)

- libVLC 옵션은 VLC for Android 기본값을 따릅니다: `--audio-time-stretch`, `--avcodec-skiploopfilter 1`(코어 3개 이상, 아니면 3),
  `--avcodec-skip-frame 0`, `--avcodec-skip-idct 0`, `--android-display-chroma RV32`. 여기에 `--avi-index=3`(색인이 깨진 AVI는
  묻지 않고 메모리에 색인을 만듦)과 `--no-sub-autodetect-file`을 더합니다. 옵션 이름은 libvlc.so 문자열로 확인했습니다
  (모르는 옵션이 있으면 libVLC가 아예 시작하지 않음).
- VLC가 띄우려는 대화상자(질문·오류)는 `Dialog.setCallbacks`로 받아, 질문은 계속 재생하는 첫 번째 선택으로 답하고 오류는
  진단 정보에 남기며 오류 화면에 보여 줍니다.
- 디코딩(`core/player/Playback.kt`의 `DecoderChoice`): 휴대폰 하드웨어(MediaCodec)는 H.264·H.265·VP8·VP9·AV1에만 씁니다.
  AVI·DivX·MPG·MPEG·VOB·WMV·ASF·FLV·RM·RMVB·3GP 등은 처음부터 VLC 자체(FFmpeg) 디코더로 엽니다. DivX/Xvid(MPEG-4 ASP)·
  MPEG-1/2·WMV·H.263은 휴대폰 디코더에서 초록 화면·멈춤·오류가 잦기 때문입니다(VLC 사용자들이 손으로 하던 설정).
- 하드웨어로 연 파일은 ① 오류가 나거나 ② 준비됐을 때 안의 영상 코덱이 위 목록 밖이거나 ③ 재생 6초가 지나도 화면이 없으면
  그 위치부터 소프트웨어 디코딩으로 다시 엽니다(파일당 한 번). 사진 뷰어 안 재생도 ①·②를 똑같이 합니다.
- 더보기 › 디코딩: 자동(위 규칙) / 소프트웨어(항상 VLC 자체 디코더). 오류 화면의 ‘다시 시도’는 소프트웨어로 엽니다.
- 설정 › 버전에 빌드 커밋과 시각이 나와서, 어떤 APK가 설치됐는지 확인할 수 있습니다.
  - 테스트: libVLC는 PC에서 돌지 않으므로 `Engines.factory`를 바꿔 테스트에서만 `MediaPlayerEngine`(Robolectric 대역)을 씁니다.
- 권한은 추가하지 않았습니다(인터넷·포그라운드 서비스·알림 권한 없음).

## 사진 뷰어 안 재생

- 사진 뷰어(갤러리·파일 목록)에서 동영상 페이지는 화면에 멈춰 선 페이지만 그 자리에서 재생합니다(`ui/gallery/InlineVideo.kt`).
  넘기는 중이거나 옆 페이지는 정지 화면만 보여 주고 디코더를 놓습니다.
- 엔진은 전체 플레이어와 같은 VLC입니다.
- 조작은 재생/일시정지, 탐색 바, 두 번 탭뿐이고, 아래쪽 ‘플레이어’로 전체 플레이어를 그 위치부터 엽니다.

## 진단

- VLC는 네이티브 코드라 오류가 나면 앱 전체가 종료됩니다. 진단 정보(설정 › 저장소)에 Android가 기록한 최근 종료 이유
  (`ApplicationExitInfo`, 네이티브 오류 포함)와 재생 오류 기록이 들어갑니다.

## MX Player를 참고한 화면

- **상단 바**: 뒤로, 파일 이름과 순번(3 / 12), 자막, 오디오 트랙(2개 이상), 화면 회전, 재생 목록, 더보기
- **하단 바**: 현재 시간 · 얇은 탐색 바 · 전체 시간(누르면 남은 시간), 그 아래 잠금 · 이전 · 재생/일시정지 · 다음 · 화면 맞춤.
  음악은 잠금·화면 맞춤 대신 무작위·반복 버튼
- **상태 칩**: 탐색 바 위에 1x가 아닌 속도, A-B, 취침 타이머 남은 시간, 반복을 작게 표시
- **제스처**

  | 동작 | 위치 | 결과 |
  |---|---|---|
  | 탭 | 어디든 | 조작부 표시·숨김(재생 중 3.5초 뒤 자동 숨김) |
  | 두 번 탭 | 왼쪽·오른쪽 1/3 | 10초 뒤로·앞으로, 이어서 탭하면 10초씩 누적 |
  | 두 번 탭 | 가운데 | 재생·일시정지 |
  | 좌우로 밀기 | 어디든 | 탐색(짧은 영상은 화면 폭 = 전체 길이, 긴 영상은 2분), 중앙에 `+0:15 / 1:23 / 12:34` |
  | 위아래로 밀기 | 왼쪽 절반 | 밝기(이 화면에서만, 닫으면 원래대로) |
  | 위아래로 밀기 | 오른쪽 절반 | 미디어 볼륨 |
  | 두 손가락 | 어디든 | 확대(최대 400%)와 이동 |
  | 길게 누르기 | 어디든 | 누르는 동안 2배속 |

- **패널**: 가로 화면은 오른쪽, 세로 화면은 아래에서 올라와 영상을 가리지 않게 했습니다(더보기·속도·자막·오디오·취침 타이머·재생 목록·정보).
- **이어서 재생 안내**: 대화상자 대신 아래쪽에 ‘1:23부터 이어서 재생 · 처음부터’를 6초 동안 보여 줍니다.

## 코드 구조

- `core/player/Playback.kt`, `core/player/Subtitles.kt`: 순수 Kotlin. 화면 맞춤 계산, 재생 목록 순서, 이어서 재생 규칙, 자막 파서. `PlayerCoreTest`
- `data/PlayerStore.kt`: 화면 맞춤·반복·무작위·회전·자막 크기와 파일별 재생 위치(SharedPreferences)
- `ui/player/Engines.kt`: `Engine` 인터페이스, `VlcEngine`(libVLC), `Engines.factory`(테스트에서 바꿈)
- `ui/player/PlayerModel.kt`: 엔진 하나와 재생 목록, 자막, 오디오 포커스, 이어폰 분리, `MediaSession`(이어폰 버튼).
  `MainViewModel`이 들고 있어서 화면이 바뀌어도 재생이 이어집니다. 화면은 `Surface`만 빌려 줍니다.
- `ui/player/PlayerScreen.kt`(화면·제스처·바), `PlayerPanels.kt`(패널), `PlayerSystem.kt`(밝기·볼륨·회전·PIP·시스템 바·백그라운드 일시정지)
- `AndroidManifest.xml`: `configChanges`로 회전 때 액티비티를 다시 만들지 않아 영상이 끊기지 않고, `supportsPictureInPicture`로 PIP를 켭니다.

## 기기에서 확인할 것

Robolectric은 영상을 디코딩하지 않아서 테스트 스크린샷의 영상 영역은 검게 나옵니다. 기기에서 다음을 확인해 주세요.

- MP4·MKV 재생과 첫 프레임, 회전할 때 끊김이 없는지, 일시정지 중 회전해도 화면이 남는지
- 밝기·볼륨 제스처, 두 번 탭 탐색, 길게 눌러 2배속, 확대
- PIP 진입과 PIP 창의 버튼, PIP 창을 닫으면 재생이 멈추는지
- 이어폰 분리 시 일시정지, 블루투스 버튼
- MKV 내장 자막과 여러 오디오 트랙(기기마다 다름)
- MP4·MKV·AVI(DivX·Xvid)·WMV·FLV·MPG 재생, 탐색·배속·회전·PIP
- MKV 내장 자막(특히 PGS·ASS) 선택과 싱크, 회전 후에도 자막이 남는지, 한국어 내장 자막 자동 켜짐, 오디오 싱크, 디코딩 전환
- 자막 파일 열기(다른 폴더·USB), 다시 열었을 때 기억되는지, USB 동영상의 같은 폴더 자막 자동 선택

# 내장 플레이어

파일 탐색기 안에서 동영상과 음악을 재생하는 플레이어입니다. 기능은 VLC for Android를 기준으로 고르고,
화면과 조작은 MX Player를 참고했습니다.

## 제약과 선택

- 이 앱은 오프라인 전용이고 새 라이브러리를 넣지 않습니다(`CLAUDE.md`). 그래서 libVLC(네이티브 FFmpeg, 수십 MB)나
  ExoPlayer(Media3)는 쓰지 않고 **Android 기본 `MediaPlayer` + `TextureView` + Compose**로 만들었습니다.
- 그 결과 재생 가능한 형식은 **기기의 디코더**가 정합니다. 보통 MP4·MKV·WebM·3GP·TS(H.264/H.265/VP9/AV1, AAC/MP3/Opus/FLAC)는
  되고, AVI·WMV·FLV·RMVB는 대부분의 기기에서 안 됩니다. 열지 못하면 오류 화면에서 ‘다른 앱으로 열기’와 ‘다음 파일’을 보여 줍니다.
- 권한은 추가하지 않았습니다(인터넷·포그라운드 서비스·알림 권한 없음).

## VLC 기능 분석과 반영 여부

| VLC for Android 기능 | 이 앱 | 비고 |
|---|---|---|
| 거의 모든 코덱·컨테이너(자체 디코더) | 부분 | 기기 디코더만 사용. 미지원 파일은 다른 앱으로 안내 |
| 하드웨어/소프트웨어 디코딩 선택 | 없음 | `MediaPlayer`는 선택할 수 없음 |
| 폴더 재생 목록, 자동으로 다음 파일 | 있음 | 파일 목록에 보이는 순서(정렬·검색 결과 그대로) |
| 반복(한 개·전체), 무작위 | 있음 | 설정은 다음 실행에도 유지 |
| 구간 반복(A-B) | 있음 | 탐색 바에 구간 표시 |
| 재생 속도 | 있음 | 0.25~4배, 0.05 단위, 길게 눌러 2배속 |
| 이어서 재생 | 있음 | 동영상과 10분 넘는 음성 파일. 최근 300개 기억, 설정에서 끔 |
| 제스처(밝기·볼륨·탐색·두 번 탭·확대) | 있음 | MX 배치. 화면 위·아래 끝은 시스템 제스처용으로 비워 둠 |
| 화면 맞춤(맞춤·채우기·늘리기·원본·16:9·4:3) | 있음 | 마지막 선택 유지 |
| 화면 회전 고정 | 있음 | 동영상 방향(가로 영상이면 가로)·가로·세로 |
| 조작 잠금 | 있음 | 잠그면 탭해도 잠금 해제 버튼만 보임 |
| PIP(화면 속 화면) | 있음 | 이전·재생/일시정지·다음 버튼. PIP 창을 닫으면 재생 종료 |
| 백그라운드 재생·알림 컨트롤·잠금 화면 컨트롤 | **없음** | 포그라운드 서비스(`mediaPlayback`) 권한과 Play Console 선언이 필요해 보류 |
| 외부 자막 자동 로드(srt·ass·ssa·vtt·smi) | 있음 | 같은 이름 우선, 기기 언어(한국어) 파일 우선. smi는 언어별 선택 |
| 자막 인코딩 | 있음 | UTF-8/UTF-16(BOM 포함)·CP949 자동 판별 |
| 자막 싱크·크기 | 있음 | 0.1초·1초 단위, 60~200% |
| 자막 색·배경·글꼴 | 없음 | 흰 글자 + 검은 테두리 고정 |
| 내장 자막 트랙 | 부분 | `MediaPlayer`가 주는 타임드 텍스트 트랙만(기기·형식에 따라 다름) |
| 자막 내려받기(OpenSubtitles) | 없음 | 오프라인 앱 |
| 오디오 트랙 선택 | 있음 | 2개 이상일 때 상단에 버튼 |
| 오디오 싱크(지연) | 없음 | `MediaPlayer` 미지원 |
| 이퀄라이저 | 없음 | 후속 후보(`android.media.audiofx.Equalizer`, 기기마다 동작 차이) |
| 취침 타이머 | 있음 | 15~90분, 현재 파일이 끝나면 |
| 이어폰 분리 시 일시정지, 이어폰·블루투스 버튼 | 있음 | 오디오 포커스(전화 등)도 처리 |
| 네트워크 스트림·SMB·UPnP | 없음 | 오프라인 앱 |
| 미디어 라이브러리 | 대체 | 갤러리와 파일 목록이 그 역할 |
| 챕터, 스냅샷, 시간 입력해서 이동 | 없음 | 후속 후보 |

## MX Player를 참고한 화면

- **상단 바**: 뒤로, 파일 이름과 순번(3 / 12), 자막, 오디오 트랙(2개 이상), 화면 회전, 재생 목록, 더보기
- **하단 바**: 현재 시간 · 얇은 탐색 바 · 전체 시간(누르면 남은 시간), 그 아래 잠금 · 이전 · 재생/일시정지 · 다음 · 화면 맞춤.
  음악은 잠금·화면 맞춤 대신 무작위·반복 버튼
- **상태 칩**: 탐색 바 위에 1x가 아닌 속도, A-B, 취침 타이머 남은 시간, 반복을 작게 표시
- **제스처**

  | 동작 | 위치 | 결과 |
  |---|---|---|
  | 탭 | 어디든 | 조작부 표시·숨김(재생 중 3.5초 뒤 자동 숨김) |
  | 두 번 탭 | 왼쪽·오른쪽 1/3 | 10초 뒤로·앞으로, 이어서 탭하면 10초씩 누적 |
  | 두 번 탭 | 가운데 | 재생·일시정지 |
  | 좌우로 밀기 | 어디든 | 탐색(짧은 영상은 화면 폭 = 전체 길이, 긴 영상은 2분), 중앙에 `+0:15 / 1:23 / 12:34` |
  | 위아래로 밀기 | 왼쪽 절반 | 밝기(이 화면에서만, 닫으면 원래대로) |
  | 위아래로 밀기 | 오른쪽 절반 | 미디어 볼륨 |
  | 두 손가락 | 어디든 | 확대(최대 400%)와 이동 |
  | 길게 누르기 | 어디든 | 누르는 동안 2배속 |

- **패널**: 가로 화면은 오른쪽, 세로 화면은 아래에서 올라와 영상을 가리지 않게 했습니다(더보기·속도·자막·오디오·취침 타이머·재생 목록·정보).
- **이어서 재생 안내**: 대화상자 대신 아래쪽에 ‘1:23부터 이어서 재생 · 처음부터’를 6초 동안 보여 줍니다.

## 코드 구조

- `core/player/Playback.kt`, `core/player/Subtitles.kt`: 순수 Kotlin. 화면 맞춤 계산, 재생 목록 순서, 이어서 재생 규칙, 자막 파서. `PlayerCoreTest`
- `data/PlayerStore.kt`: 화면 맞춤·반복·무작위·회전·자막 크기와 파일별 재생 위치(SharedPreferences)
- `ui/player/PlayerModel.kt`: `MediaPlayer` 하나와 재생 목록, 자막, 오디오 포커스, 이어폰 분리, `MediaSession`(이어폰 버튼).
  `MainViewModel`이 들고 있어서 화면이 바뀌어도 재생이 이어집니다. 화면은 `Surface`만 빌려 줍니다.
- `ui/player/PlayerScreen.kt`(화면·제스처·바), `PlayerPanels.kt`(패널), `PlayerSystem.kt`(밝기·볼륨·회전·PIP·시스템 바·백그라운드 일시정지)
- `AndroidManifest.xml`: `configChanges`로 회전 때 액티비티를 다시 만들지 않아 영상이 끊기지 않고, `supportsPictureInPicture`로 PIP를 켭니다.

## 기기에서 확인할 것

Robolectric은 영상을 디코딩하지 않아서 테스트 스크린샷의 영상 영역은 검게 나옵니다. 기기에서 다음을 확인해 주세요.

- MP4·MKV 재생과 첫 프레임, 회전할 때 끊김이 없는지, 일시정지 중 회전해도 화면이 남는지
- 밝기·볼륨 제스처, 두 번 탭 탐색, 길게 눌러 2배속, 확대
- PIP 진입과 PIP 창의 버튼, PIP 창을 닫으면 재생이 멈추는지
- 이어폰 분리 시 일시정지, 블루투스 버튼
- MKV 내장 자막과 여러 오디오 트랙(기기마다 다름)
- AVI 등 미지원 파일에서 오류 화면이 뜨는지
